사내 시스템 "PRISM"의 랜딩 페이지를 만들어줘. PRISM은 PRoduct Information System Management의 약자야.

## 기술 조건
- HTML 파일 하나로 완성 (CSS, JS 모두 파일 안에 포함). 외부 라이브러리 사용 금지, 순수 JavaScript + Canvas 2D만 사용.
- 폰트: Google Fonts의 Manrope(영문 제목, 400/500/700/800)와 Noto Sans KR(한글 본문, 400/500/700). 폰트가 없을 때를 위해 -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif 순으로 대체 폰트 지정.
- 밝은 테마 하나만 사용 (다크모드 없음).
- 데스크톱, 태블릿, 모바일(390px)에서 모두 깨지지 않게. 가로 스크롤이 생기면 안 됨.
- prefers-reduced-motion 설정이 켜져 있으면 모든 애니메이션을 끄고 완성된 정지 화면을 보여줄 것.

## 색상
- 배경 #ffffff, 본문 글자 #0e0e12, 보조 글자 #64646c, 흐린 글자 #a0a0a8, 구분선 rgba(14,14,18,.1)
- 메뉴 포인트 색: 바로가기 #ff6a3d(주황빨강), 제품현황 #34c759(초록), 아이디어게시판 #0fb5c9(청록), 수신처관리 #6e5cf0(보라)

## 레이아웃 (위에서 아래로)
1. 상단 바: 왼쪽에 작은 로고(무지개색 물결선 3개 SVG) + "PRISM" (Manrope 800, 자간 넓게), 오른쪽에 "INTERNAL" 알약 모양 태그.
2. 헤드라인 영역 (왼쪽 정렬):
   - 작은 글씨로 "PRoduct Information System Management" — P, R, I, S, M 글자만 진하게, 나머지는 흐린 회색.
   - 아주 큰 "PRISM" (Manrope 800, 크기 clamp(72px, 11.5vw, 148px), 자간 -0.06em, 줄간격 0.9).
   - 한 줄 소개: "제품의 모든 정보를 **한 결로 엮어** 보여줍니다." (굵은 부분만 진한 색)
3. 리본이 지나가는 빈 공간 (높이 약 clamp(200px, 30vh, 300px)).
4. 메뉴 4칸 (가로 4열, 위쪽과 칸 사이에 얇은 구분선). 각 칸 구성:
   - 위쪽에 포인트 색의 짧은 막대(28×3px, 둥근 모서리)
   - 메뉴 이름(굵게), 영문명(작고 흐리게), 한 줄 설명, 오른쪽 위에 → 화살표
   - 바로가기 / Shortcuts / 자주 쓰는 시스템과 문서로 한 번에 이동
   - 제품현황 / Products / 제품별 상태, 사양, 일정을 한눈에
   - 아이디어게시판 / Ideas / 제안하고, 모으고, 함께 다듬기
   - 수신처관리 / Recipients / 배포와 알림을 받을 사람, 그룹 관리
   - 메뉴 칸 배경은 반투명 흰색(rgba(255,255,255,.72))으로 해서 뒤로 리본이 은은하게 비치게.
   - 860px 이하에서는 2열×2행으로 배치.
5. "다시 재생" 버튼(테두리만 있는 알약 버튼)과 안내 문구 한 줄.
6. 푸터: 왼쪽 "PRISM · PRoduct Information System Management", 오른쪽 "랜딩 페이지 샘플".

## 리본 애니메이션 (핵심)
화면 전체 뒤에 Canvas를 깔고(z-index로 글자 뒤), 가는 무지개 선 여러 가닥으로 짠 "실크 리본"을 그려줘.
- 선 개수: 데스크톱 64가닥, 화면 폭 560px 미만이면 44가닥. 선 굵기 약 0.9px, 투명도 약 0.42.
- 각 선의 색은 위→아래 순서로 빨강(2°) → 주황(22°) → 노랑(48°) → 초록(128°) → 청록(188°) → 파랑(228°) → 보라(262°) 색상환을 따라 부드럽게 보간. hsla(색상, 88%, 54%, 투명도).
- 리본의 중심선은 3번 "빈 공간"의 세로 중앙(CY)을 기준으로 함. AMP = 빈 공간 높이 × 0.95 (모바일은 × 0.6), 최대 260px.
- 각 선은 x를 10px 간격으로 찍어 이은 선이고, 가닥 번호를 s(0~1), 가로 위치를 u = x/화면폭, 시간을 t(초)라고 할 때:
  - 중심 높이: cy = CY + AMP×0.28×sin(u×π×1.35 + t×0.32) + AMP×0.1×sin(u×π×4 − t×0.55)
  - 리본 폭(부호가 바뀌면서 리본이 꼬이는 효과): w = AMP × sin(u×π×1.1 + t×0.2 + 0.9)
  - 선의 y = cy + (s − 0.5) × w + sin(u×11 + s×5 + t×0.8) × 2.2
- 폭 w가 0을 지나는 지점에서 리본이 한 번 비틀리며 빨강과 보라의 위치가 뒤바뀌는 것이 포인트.

## 등장 애니메이션
- 페이지가 열리면 리본이 왼쪽 끝에서 오른쪽 끝까지 약 2.4초에 걸쳐 그려지며 나타남 (0.3초 후 시작, ease-in-out).
- 텍스트들은 아래에서 16px 올라오며 블러(10px)가 풀리고 투명도 0→1로 나타남. 순서: 약어 0.2초 → PRISM 0.3초 → 소개 0.5초 → 메뉴 4칸이 1.6초부터 0.1초 간격으로 하나씩.
- "다시 재생" 버튼을 누르면 리본 그리기와 텍스트 등장을 처음부터 다시 재생.

## 인터랙션
1. **마우스를 따라 리본이 일렁임**
   - 마우스 위치는 매 프레임 12%씩 따라가게 부드럽게 보간.
   - 영향 범위: 마우스 x와의 거리 dx에 대해 infl = exp(−dx² / (2σ²)), σ = max(110px, 화면폭×0.1). 마우스가 화면을 벗어나면 영향력을 서서히 0으로.
   - 마우스 근처 리본이 커서 쪽으로 살짝 기울어짐: lean = clamp((마우스y − cy) / (AMP×1.6), −1, 1) × AMP × 0.2
   - 잔물결: ripple = sin(dx×0.045 − t×6 + s×2.6) × (3 + 16×에너지)
   - 에너지는 마우스를 빨리 움직일수록 커지고(이동거리×0.012 누적, 최대 1), 매 프레임 0.965배로 줄어듦. 즉 가만히 있으면 잔잔하고, 휘저으면 크게 출렁임.
   - 최종: y += infl × (lean + ripple) + infl × (s − 0.5) × w × 0.12 (마우스 근처에서 리본이 살짝 벌어짐)
2. **메뉴 호버 시 색 강조**: 리본을 4등분(빨강, 초록, 청록, 보라 구간)해서 각 메뉴와 연결. 메뉴에 마우스를 올리면 그 구간 선은 투명도 2배, 굵기 약간 증가, 나머지 구간은 투명도 0.22배로 흐려짐. 변화는 매 프레임 8%씩 부드럽게.
3. 메뉴 호버 시 위쪽 색 막대가 칸 전체 폭으로 늘어나고, 화살표가 오른쪽으로 4px 이동.
4. 메뉴 링크 주소가 "#"으로 시작하는 동안은 클릭 시 이동하지 말고 화면 아래에 "○○로 이동합니다 · 샘플이라 링크는 아직 비어 있어요" 토스트를 2.8초간 띄워줘. 실제 주소로 바꾸면 정상적으로 이동하게.

## 기타
- Canvas는 devicePixelRatio(최대 2)를 반영해 선명하게 그리고, 창 크기가 바뀌면 ResizeObserver로 다시 계산.
- 키보드 포커스 시에도 호버와 같은 효과 + 보이는 포커스 테두리.
- 코드에 한국어 주석으로 각 부분 설명을 달아줘.
